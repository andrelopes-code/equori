# ADR 001: PostgreSQL as the database

- Status: accepted
- Date: 2026-10-14

## Context

equori is a personal finance manager with external integrations. Its schema receives frequent migrations that add columns, add constraints (`NOT NULL`, `CHECK`, `FOREIGN KEY`) and change column types.

In SQLite, these changes require the 12-step table rebuild (create new table, copy, drop, rename). The rebuild requires `PRAGMA foreign_keys=OFF`, which has no effect inside a transaction. A failure midway leaves the schema partially migrated.

## Decision

- PostgreSQL 18, driver `pgx/v5` with `pgxpool`.
- Typed queries generated by `sqlc`.
- goose migrations, embedded in the binary and applied at startup. DDL is transactional.
- Money: `bigint` in minor units + `char(3)` ISO 4217 currency code.
- Instants as `timestamptz`. Accounting dates as `date`.
- New constraint on a populated table: `ADD CONSTRAINT ... NOT VALID`, then `VALIDATE CONSTRAINT`.

## Consequences

- `compose.yaml` has 2 services (`app`, `db`). The Postgres major version is pinned in the image tag.
- Integration tests run against the development Postgres (`make db-up`). `pgtest.New` creates, migrates and drops one database per test.
- Postgres major upgrades are the host's responsibility. The procedure is documented in the README.

## Amendment of 2026-10-26 (ADR 022)

- Managed mode runs PostgreSQL as a child of `equori` over a data directory (`internal/platform/pgcluster`).
- The minimum major is 18: the migrations call `uuidv7()`.
- Major upgrades stay the host's responsibility for compose and follow ADR 022 V6 for managed mode.
