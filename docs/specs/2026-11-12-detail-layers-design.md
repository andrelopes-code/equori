# Detail layers and content audit

Two changes under one rule: reference content leaves the page body for a layer opened on demand, and every block that stays or moves is audited for content that earns no place. Amends `docs/specs/2026-11-11-instrument-page-design.md` (IP1, the Quote and Position sections) and `docs/specs/2026-11-09-return-clarity-design.md` (RC6).

## 2. Rules

| ID  | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CA1 | A figure is drawn only when it answers a question of its screen and supports a decision.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| CA2 | A zero, an empty value or "—" repeated along a row or a column is not drawn. A block with no data draws one empty state in place of its cards, chart and table.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| CA3 | A number is written once per screen, in the highest-ranked place. A later copy is cut.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| CA4 | A block opens with one lead figure, then supporting figures grouped by meaning, then detail. No block opens with a table.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| CA5 | A table appears where rows are compared or looked up. A table with one row is a sentence or a card.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| DL1 | Reference content (every point of a series, an audit, a method, a log, a source list) never mounts in the page body. The page draws one summary line and one button that opens a layer. A disclosure of form fields or of assistant activity stays a `Collapsible`.                                                                                                                                                                                                                                                                                                                                         |
| DL2 | One shared layer, `ui/dialogs/detail-dialog.tsx`: a `Dialog` with a title, a one-sentence description, a body and one close button. The body mounts only while the layer is open. The summary line and the trigger sit side by side in the page.                                                                                                                                                                                                                                                                                                                                                            |
| DL3 | Space. The layer is at most 1200 px wide and keeps 48 px of the viewport free on each side: 1200 px at 1440 px, 1184 px at 1280 px, 928 px at 1024 px. Its height is at most the viewport height minus 96 px, and only the body scrolls. The owner review of 2026-11-12 narrowed the layer from the viewport minus 48 px, which sat too close to the edges. A sticky table header inside a layer takes the layer's raised surface, not the page ground. Slice 1 measured `xl` at 786 px and `full` at 1400 px at 1440 px, so the layer is `full` capped through `className` in a co-located `*.module.css`. |
| DL4 | Layout. A body is a grid, not one stacked column: a full-width figure strip, then the main content (table or text) beside an aside of notes or legend from 1024 px. The figure strip and the table header stay visible while the table scrolls.                                                                                                                                                                                                                                                                                                                                                             |
| DL5 | `ui/dialogs/detail-section.tsx` is one titled section of a body.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## 4. Page changes

| ID  | Block                  | Change                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q1  | Instrument Quote       | The card "Variação no intervalo" no longer repeats the price of the hero (CA3). It becomes a card of the size of its neighbours whose value is the signed change of the range, in the tone of its direction, and whose note is the two dates of the range. Its range sentence no longer overflows the card. The other three figures (highest, lowest, points) stay. "Cotações no intervalo" states "in the range" in its label. |
| Q2  | Instrument Position    | The four figure cards stay. The table "Contas que têm este item" is drawn only when two or more accounts hold the instrument; with one account its name goes under the first card (CA5).                                                                                                                                                                                                                                        |
| Q3  | Card statement figures | The figures read as one line of the bill: previous balance, purchases, credits, payments, total. A term equal to zero is not drawn (CA2). "Em aberto" is one note under the line, not a card.                                                                                                                                                                                                                                   |
| Q4  | Categories tree        | A `Switch` "Show categories without movement" (pt-BR "Mostrar categorias sem movimento"), off by default, beside "Show archived". While off, a row with zero value and zero direct value is hidden, and so is a group whose rows are all hidden. The label names the number of hidden rows (CA2). The share bar column stays; the composition chart keeps its role.                                                             |
| Q5  | Portfolio warnings     | When the page-level warning about late or missing quotes is drawn, the missing-price alert of the return section is drawn as one muted sentence with the same message and no button, so the region holds one `Alert` with one action (O14). When only the return-section alert applies, it stays an alert.                                                                                                                      |
| Q6  | Net worth empty state  | With no monthly net worth, the tab draws one empty state in place of the three cards, the chart and the table (CA2).                                                                                                                                                                                                                                                                                                            |

## 5. Slices

One vertical slice per commit, in this order. Each slice starts with a failing test. A plan holds at most four slices of three tasks (`docs/contributing/agents.md`); this spec is two plans.

Plan 1, layers: (1) `detail-dialog.tsx`, `detail-section.tsx`, L1; (2) L2, L7; (3) L3 with `reconciliation.ts`; (4) L4, L5, L6.

Plan 2, pages: Q1 and Q2; Q3; Q4 and Q6; Q5.

Slice 1 of plan 1 measures the open layer of an instrument with 7305 prices on `make run-prod` at 390 px with the CPU throttled 4x. A cost above one frame per interaction opens a Slotted finding for row windowing in `Table`.

## 7. Tests

- The tests that open a collapsible (`return-view`, `portfolio-return`, `instrument-page`, `account-page`) change their expectations from "open the collapsible" to "open the layer". The commit body names the rule (DL1) and the block (L1 to L7).
- A layer test checks that the body is absent before the button is pressed and present after.
- A test per page change checks the removed element (Q1 to Q6) and the kept element beside it.
- `reconciliation.test.ts` covers deposits only, withdrawals only, no flows and a flow in another currency.
- Each new file receives one injected defect before its slice is committed; a defect no test catches is reported as uncovered.
