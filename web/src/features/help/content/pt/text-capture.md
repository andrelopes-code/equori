# Registrar transações por texto

A tela [Registrar por texto](/transactions/capture) registra várias transações de uma vez. Cada linha escrita vira um rascunho: o equori lê nela o valor, a data, a conta e a categoria. Nada é registrado antes da confirmação.

## Registrar as linhas

![Vídeo: o registro de duas transações por texto, até o botão Registrar](text-capture.video)

1. Escreva uma transação por linha. Uma linha que não cita conta usa a **Conta padrão**.
   ![A tela Registrar por texto, com a conta padrão e a caixa de texto marcadas](capture-text)
2. Confira os rascunhos. Para mudar o que foi lido de uma linha, escolha **Editar**.
   ![Os rascunhos das duas linhas, marcados](capture-drafts)
3. Mude o que faltou, como a **Categoria**, e escolha **Aplicar**.
   ![O diálogo de uma linha, com o campo Categoria marcado](capture-category)
4. Escolha **Registrar …**. O botão traz o número de rascunhos. A tecla Ctrl com Enter faz o mesmo.
   ![O rodapé da tela, com o botão Registrar marcado](capture-record)

Depois de registrar, o aviso diz quantas transações entraram, com o botão **Ver**, que abre a lista de transações.

## Como escrever uma linha

Uma linha junta, em qualquer ordem:

- o valor, como 230,50;
- a data, como ontem, sexta ou 12/10; sem data, vale o dia de hoje;
- a conta ou o cartão, pelo nome ou pelo final do número, como final 1234;
- o número de parcelas de uma compra no cartão, como 3x;
- uma tag, depois de #.

O resto da linha vira a descrição. No rascunho, as palavras lidas aparecem marcadas.

## Os rascunhos

Cada rascunho mostra a data, a conta, a categoria e o valor. Ao lado da categoria, o rascunho diz de onde ela veio: **por regra**, **pelo histórico** ou **sugerida pela IA**. Uma linha sem conta e sem conta padrão aparece entre os rascunhos que precisam de atenção, com o motivo. Corrija a linha ou escolha a conta padrão antes de registrar.

Uma mudança feita em **Editar** substitui o que foi lido da linha até o texto dela mudar.

Para registrar uma transação com todos os campos à vista, escolha **Usar formulário**: veja [Registrar uma transação](/help/record-transaction).
