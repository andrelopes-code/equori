# Criar um orçamento

Um orçamento é um valor mensal para uma categoria. A cada mês, o equori compara esse valor com o que a categoria gastou.

## Criar o orçamento

![Vídeo: a criação de um orçamento, até o botão Criar orçamento](create-budget.video)

1. Em [Novo orçamento](/planning/budgets/new), escolha a **Categoria**.
   ![O formulário Novo orçamento, com o campo Categoria marcado](budget-category)
2. Digite o **Valor mensal**.
   ![O formulário, com o campo Valor mensal marcado](budget-amount)
3. Confira o **Primeiro mês**. As setas mudam o mês.
   ![O formulário, com o campo Primeiro mês marcado](budget-month)
4. Marque **Transportar o saldo para o mês seguinte** quando o que sobrar, ou exceder, deve passar para o mês seguinte.
   ![O formulário, com a opção de transportar o saldo marcada](budget-carry)
5. Escolha **Criar orçamento**.
   ![O rodapé do formulário, com o botão Criar orçamento marcado](budget-create)

Depois de criado, a página do orçamento abre. Uma categoria tem um orçamento só: quando ela já tem um, a página desse orçamento abre no lugar.

## Saldo transportado

Uma despesa anual, como um seguro, cabe num orçamento com saldo transportado: o valor mensal se acumula até o mês da despesa. Dinheiro guardado numa conta separada é uma [meta](/goals).

## Onde os orçamentos aparecem

A aba **Orçamentos** de [Planejamento](/planning) mostra os orçamentos do mês, com o planejado e o gasto. Para dividir um valor entre vários orçamentos de uma vez, veja [O plano do mês](/help/budget-plan).
