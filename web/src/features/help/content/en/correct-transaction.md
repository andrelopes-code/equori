# Correct or void a transaction

A transaction recorded wrong is corrected, and a transaction that should not exist is voided. Both actions keep a reason in the history of the transaction.

## Correct a transaction

![Video: correcting the amount of a transaction, up to the Save correction button](correct-transaction.video)

1. On [Transactions](/transactions), open the transaction with a double click.
   ![The list of transactions, with the transaction to open marked](correct-open)
2. In the panel beside the list, open **Transaction actions**, the button with three dots.
   ![The panel of the transaction, with its header marked](correct-menu)
3. Choose **Correct**.
   ![The menu of the transaction actions, marked](correct-choose)
4. Change what is wrong, such as the **Amount**.
   ![The Correct transaction form, with the Amount field marked](correct-fields)
5. Write the **Reason for the correction**.
   ![The form, with the Reason for the correction field marked](correct-reason)
6. Choose **Save correction**.
   ![The foot of the form, with the Save correction button marked](correct-save)

A correction creates a new version of the transaction. The earlier version stays in the **History** of the transaction, with the reason. Once saved, the notice **Correction saved** shows and the page of the transaction opens.

A reconciled transaction cannot be corrected: see [Check an account's balance](/help/check-balance).

## Void a transaction

A voided transaction stays in the history and leaves every balance and report. It is the way out for a duplicated transaction.

1. In the **Transaction actions** menu, choose **Void**.
2. Write the **Reason**, of at most 500 characters.
3. Choose **Void**.

The list of transactions hides voided ones. Turn on **Show voided** to see them.
