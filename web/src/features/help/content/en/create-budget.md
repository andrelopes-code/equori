# Create a budget

A budget is a monthly amount for one category. Each month, equori compares that amount with what the category spent.

## Create the budget

![Video: creating a budget, up to the Create budget button](create-budget.video)

1. On [New budget](/planning/budgets/new), choose the **Category**.
   ![The New budget form, with the Category field marked](budget-category)
2. Type the **Monthly amount**.
   ![The form, with the Monthly amount field marked](budget-amount)
3. Check the **First month**. The arrows change the month.
   ![The form, with the First month field marked](budget-month)
4. Tick **Carry the balance to the next month** when what is left, or overspent, should pass to the next month.
   ![The form, with the option to carry the balance marked](budget-carry)
5. Choose **Create budget**.
   ![The foot of the form, with the Create budget button marked](budget-create)

Once created, the page of the budget opens. A category holds one budget: when it has one already, the page of that budget opens instead.

## Carried balance

A yearly expense, such as an insurance, fits a budget whose balance carries over: the monthly amount builds up until the month of the expense. Money kept in a separate account is a [goal](/goals).

## Where budgets show

The **Budgets** tab of [Planning](/planning) shows the budgets of the month, with the planned and the spent amounts. To split one amount among several budgets at once, see [The month's plan](/help/budget-plan).
