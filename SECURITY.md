# Security policy

equori stores personal financial data. Security reports are handled before any other work.

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the affected version (`equori version`), reproduction steps and impact.

Expected timeline:

- Acknowledgement within 7 days.
- Fix or mitigation plan within 30 days of acknowledgement.

## Supported versions

Only the latest release receives security fixes.
